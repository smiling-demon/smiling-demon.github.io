PROJECT / 012026 · ВКР

LLM Symbolic ODE Reasoning ↗

PyTorch · Transformers · SymPy

Исследование того, как языковые модели рассуждают при символьном решении обыкновенных дифференциальных уравнений.

  • Разработал pipeline: генерация решения в LaTeX и автоматическая проверка корректности через SymPy.
  • Исследовал Qwen2.5-3B, 7B и 14B на 5 классах ОДУ в 8 конфигурациях reasoning, включая CoT, ToT, RSA и их комбинации.
  • Реализовал оценку на основе CAS: алгебраическая эквивалентность и корректность подстановки; BLEU использовался как дополнительная метрика.
  • Сформулировал критерий выбора модели и стратегии по компромиссу «качество — время» для субагентной системы с локальными LLM.

PROJECT / 022024 · Командный

RuSigLIP ↗

PyTorch · Transformers · Accelerate · Weights & Biases

Русскоязычная image-text модель SigLIP-подобного типа. Командный проект из 3 человек.

  • Полностью реализовал distributed training pipeline по подходу из оригинальной работы SigLIP.
  • Организовал обучение на 8 GPU H100 с помощью Accelerate.
  • Достиг global batch size около 6400.

PyTorch · Gymnasium · TensorBoard

Модульная экспериментальная среда для исследования DQN при ограниченном вычислительном бюджете.
